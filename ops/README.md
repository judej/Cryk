# Operations

The reference deployment uses Linux containers, an HTTPS reverse proxy, private networking, TLS, Keycloak, OpenBao Transit, and PostgreSQL. Give each runtime role its own identity. Separate credential keys and derived-content keys. Keep bootstrap, unseal, and recovery material outside application backups.

The operator records the owner, approved processor route, account eligibility, cohort, scopes, retention, and restore targets before enrollment. An unknown or expired approval closes the affected route.

The restore procedure starts with dispatch disabled. Apply the current deletion and revocation ledger from outside the restore boundary. Invalidate uncertain authority. Resume authorized reads first. A restore drill must include key rotation and loss of authority records.

Add executable deployment configuration only after the developer approves the environment and cost.
