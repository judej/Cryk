# P07 · Pilot admission and evaluation

**Dependencies:** P06.

**Design sections:** Release scope · Release evidence and ownership in the [version 3 design](../../../docs/design/service-v3.md).

**Expected ownership:** Acceptance records and operator evidence. The planner records exact paths before assignment.

Evaluate the integrated read-only release. Keep enrollment and release decisions with the human owners.

## Acceptance criteria

- [ ] P07-1. Collect admission, isolation, privacy, recovery, and processor evidence with the named owners. Block enrollment on missing decisions.
- [ ] P07-2. Sample the declared scope independently. Measure missed obligations, false closures, useful alerts, net time saved, and due-item latency.
- [ ] P07-3. Record sample sizes, shadow results, adopted targets, actual results, rollback conditions, and the release owner's decision.
